# PC-003 — Start with a use case and budget

- **Priority:** P1 · **Status:** Backlog · **Epic:** Guided planning · **Depends on:** PC-001, PC-004, PC-005, PC-006

## User story

As a first-time PC buyer, I want to start from what I will use the computer for and how much I can spend, so that I can get a sensible starting configuration without already knowing component terminology.

## Acceptance criteria

- **Given** I choose a supported purpose (initial candidates: gaming, study/office, creation) and a budget range, **when** I request a starting point, **then** I receive a build or curated list that fits the stated range and explains its assumptions.
- **Given** there is no validated recommendation for my answers, **when** I submit them, **then** the site says it cannot recommend yet and offers catalog browsing or a contact option that works.
- **Given** I receive a recommendation, **when** I inspect it, **then** every component has a current detail page, price status, and compatibility state; unknown values are labeled unknown.
- **Given** I change the purpose or budget, **when** the result updates, **then** the page explains which parts changed and retains my inputs.

## Notes

Do not label recommendations as AI unless an AI capability is built and evaluated. Begin with reviewed/curated builds and disclose how they are selected.
